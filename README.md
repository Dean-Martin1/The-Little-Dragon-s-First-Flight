
# The Little Dragon's First Flight

## Project Overview

This is a Java programming and GitHub source control
assignment developed using Eclipse.

The project is based on a text adventure game concept
called The Little Dragon's First Flight.

Ember is a young dragon who must reach the village
beacon before sunset.

The planned game includes three paths:
- Cloud Ridge
- Whispering Forest
- River Gorge

Ember has 75 minutes and a backpack with 3 item slots.

## Current Java Implementation

The starting program demonstrates four Java access
modifiers through the GameCharacter and Ember classes.

Additional Git feature branches will introduce:
- Exception handling
- Log4j2 application logging

The complete adventure game is a proposed design,
not yet a fully implemented game.

## Development Environment

- Java
- Eclipse IDE
- Git and GitHub
- Apache Log4j 2.17.2

## Running the Project

1. Import the project into Eclipse.
2. Configure a compatible Java JDK.
3. Add the following JAR files to the lib folder:
   - log4j-api-2.17.2.jar
   - log4j-core-2.17.2.jar
4. Verify the JARs appear on the Java Build Path.
5. Run AccessModifierDemo.java.

After the logging feature is implemented, the
application will write to logs/little-dragon.log.

The JAR binaries are not stored in this repository.
